# راه‌اندازی جست‌وجوی GIF در وایرو

جست‌وجوی داخل چت با GIPHY Search API پیاده‌سازی شده است. برای فعال‌شدن نتایج، باید کلید API معتبر GIPHY را در GitHub Actions ثبت کنید.

## ساخت کلیدها
1. وارد https://developers.giphy.com/ شوید و یک حساب توسعه‌دهنده بسازید.
2. یک App از نوع API ایجاد کنید و کلید مربوط به آن را دریافت کنید.
3. طبق راهنمای GIPHY برای هر پلتفرم یک کلید جدا بسازید: Web، Android، iOS و Windows. این کلیدها برای همین قابلیت جست‌وجوی GIF در چت هستند.

## افزودن کلیدها به GitHub
در مخزن `zahraghaderi8992-max/vyro-social` وارد مسیر زیر شوید:

**Settings → Secrets and variables → Actions → Repository secrets → New repository secret**

چهار Secret زیر را جداگانه ایجاد کنید:

| نام Secret | کلید مربوط به |
|---|---|
| `GIPHY_API_KEY_WEB` | نسخهٔ وب |
| `GIPHY_API_KEY_ANDROID` | نسخهٔ اندروید |
| `GIPHY_API_KEY_IOS` | نسخهٔ iOS |
| `GIPHY_API_KEY_WINDOWS` | نسخهٔ ویندوز |

مقدار هر Secret را خود کلید API همان پلتفرم قرار دهید. کلیدها را در کد، پیام چت یا فایل عمومی قرار ندهید.

## انتشار
بعد از ذخیرهٔ Secretها، workflow مربوط به هر پلتفرم را از بخش **Actions** با گزینهٔ **Run workflow** دوباره اجرا کنید؛ یا با commit بعدی، workflowها خودکار اجرا می‌شوند.

تا وقتی کلید وب ثبت نشده باشد، پنل GIF داخل وایرو به‌جای نتایج زنده، پیام راه‌اندازی کلید را نشان می‌دهد. لینک جست‌وجوی بیرونی و ارسال لینک مستقیم GIF همچنان به‌عنوان راه جایگزین فعال می‌مانند.

## محدودیت کلید آزمایشی
کلیدهای Beta در شروع محدودیت ۱۰۰ درخواست API در ساعت دارند. نشان «Powered by GIPHY» نیز در پنل حفظ شده است.
